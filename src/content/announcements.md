# Nouveautés

## Modifier son derby name ou son club

Vous pouvez **mettre à jour votre derby name** ou **changer de club** sans créer un second compte :

1. Ouvrez **« Ajouter mon derby name »** comme pour une première inscription.
2. Utilisez le **même e-mail** que celui déjà validé pour votre derby name actuel.
3. **Changement de club uniquement** : cochez *« Je modifie uniquement mon club »* — vous n’avez plus qu’à indiquer votre e-mail et le nouveau club, puis confirmer via le lien reçu par mail.
4. **Changement de derby name** (et éventuellement de club) : laissez la case décochée, saisissez votre **nouveau** derby name, votre numéro de roster et le club souhaité.

**Vous n’avez pas besoin de saisir votre ancien derby name** : le site vous reconnaît via votre **e-mail**. Après envoi, vérifiez votre boîte mail et cliquez sur le lien de confirmation pour valider le changement.

## Club absent de la liste

Si votre structure n’apparaît pas dans la liste, choisissez **« Autre / non listé »** ou **créez le club** après une recherche : les informations seront prises en compte après validation de l’e-mail.
